# Sky Dominion – Flight Prototype

A fast-paced top-down aerial shooter inspired by Ace Combat.

## Play

Open `index.html` in a browser, or deploy to GitHub Pages via `Settings → Pages → Deploy from branch (main / root)`.

## Controls

| Key / Button | Action |
|---|---|
| `Shift` | Afterburner / Accelerate |
| `Ctrl` | Airbrake / Decelerate |
| `Mouse` | Aim / Steer |
| `LMB` | Machine Gun (Auto-fire at RPM) |
| `Space` | Fire Standard Missile |
| `X` | Fire Special Weapon |
| `S` | Deploy Flares |
| `A` | Activate Tactical Ability |
| `Z` (Hold) | Tactical Map Mode (150% Entire AO) |
| `C` | Cycle Special Weapon |
| `1` / `2` / `3` / `4` | Switch Aircraft (Su-27 / F-15C / F-111F / Su-57) |
| `M` | Toggle Sound Effects |

## Stats

- **SPD** – Maneuverability / Turn Rate *(active in this prototype)*
- **DEF** – Defensive durability *(coming soon)*
- **AIR** – Air-to-air effectiveness *(coming soon)*
- **GND** – Ground-attack capability *(coming soon)*
